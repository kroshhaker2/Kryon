# Kryon

High-performance [Paper](https://github.com/PaperMC/Paper) fork with native optimizations.

> Kryon is experimental and does not provide stable releases yet.

## Building

Kryon requires Git and JDK 25 or newer.

```bash
./gradlew applyPatches
./gradlew createPaperclipJar
```

The resulting server JAR is written to `paper-server/build/libs`.
